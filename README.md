# Mensajes con límite — Biblioteca Legal Colombiana

Amenaza (art. 347), injuria (art. 220), calumnia (art. 221) y extorsión (art. 244) del Código Penal colombiano, explicadas para la ciudadanía.

**Publicación:** https://haroldco45.github.io/amenaza-injuria-calumnia-extorsion/

## Qué incluye
- Fichas de los 4 delitos con penas y multas convertidas a pesos 2026
- Test "¿Qué delito es?" (5 preguntas)
- Tabla y calculadora SMMLV → pesos
- Agravantes y atenuantes: arts. 223, 224, 225 y 347 inc. 2
- Guía para víctimas: líneas 123, 165, 122, denuncia virtual, lista de pruebas (localStorage) y generador de relato
- Mitos, glosario, preguntas frecuentes y fuentes
- Nota editorial: la infografía de LR muestra extorsión 192–360 meses; el texto vigente del art. 244 dice 192–288

## Subir a GitHub Pages
1. Crear el repo `amenaza-injuria-calumnia-extorsion` (en minúsculas, exacto).
2. Add file → Upload files: `index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`, `og-image.png`, `README.md` (todo en la raíz).
3. Settings → Pages → Branch `main` / root.
4. Si usa otro nombre de repo, cambie la URL en las etiquetas `og:` y en el botón Compartir de `index.html`.

## Mantenimiento
- **Cada enero:** actualizar `const SMMLV` en `index.html` y el texto del encabezado (verificar el decreto del año).
- Al cambiar archivos, subir la versión en `sw.js` (`mensajes-limite-v1` → `v2`) y el `?v=` de `og:image`.
